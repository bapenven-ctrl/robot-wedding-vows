A program that writes one line of robot wedding vows: a robot promises to love its partner until their batteries are recycled into toasters — and to keep finding them, even if they come back as a kettle.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22.18 or later (it is plain TypeScript, run as-is). It writes the vow — one line, 144 characters — to `/output/entry.txt` (UTF-8, mode 0644).
